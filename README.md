# LUẬT AI – Trợ lý pháp luật Việt Nam

Ứng dụng web AI Legal Assistant giúp người dùng đặt câu hỏi pháp lý bằng ngôn ngữ tự nhiên, phân tích tình huống, đề xuất căn cứ pháp lý và hướng xử lý thực tế theo hướng dẫn của Luật Việt Nam.

## Tính năng chính

- Chatbot pháp lý theo từng lĩnh vực
- Hệ thống câu trả lời theo cấu trúc rõ ràng
- Gợi ý câu hỏi nhanh theo nhóm lĩnh vực
- Tải lên tài liệu PDF/Word/ảnh hợp đồng
- Khung hướng xử lý, rủi ro và câu hỏi bổ sung
- Giao diện hiện đại, responsive
a
- Cấu trúc dữ liệu mở rộng cho tương lai

## Công nghệ

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- App Router API

## Chạy dự án

```bash
npm install
npm run dev
```

Mở trình duyệt tại: http://localhost:3000

## Cấu trúc dữ liệu gợi ý

- User
- Account
- ConversationHistory
- Message
- UploadedDocument
- LegalField
- LegalSource
- Feedback
- UsageStatistics

## Lưu ý pháp lý

Dự án này là ứng dụng demo/ứng dụng sản phẩm mẫu được xây dựng phục vụ mục đích tham khảo, hỗ trợ tra cứu pháp lý, không thay thế tư vấn pháp lý chuyên nghiệp.
```
